# Zoker’s Mod Menu 简体中文汉化版

Balatro（小丑牌）作弊菜单汉化，基于 [1Zoker/ZokersModMenu](https://github.com/1Zoker/ZokersModMenu) v2.1.1。

原模组作者：**Zoker / 1Zoker**。本仓库由 **Lomiry** 发布汉化，属于非官方中文版本。

## 汉化内容

- 菜单、按钮、开关、输入提示和物品选择页面。
- 初始金钱、出牌和弃牌次数、手牌上限、牌型等级、槽位与底注难度。
- 自定义牌组的花色、增强、蜡封及版本名称。
- 从游戏当前语言读取卡牌、优惠券和标签名称；没有对应翻译时保留原名称。
- 长名称按完整 UTF-8 字符截断，避免切断中文字节产生乱码。
- 修复主菜单快捷键判断，并通过 Lovely 将菜单开关及快捷键修改接入 LÖVE 键盘事件入口，避免后续按键转发绕过菜单。

保留原模组的功能、内部物品标识和快捷键。此版本汉化 Zoker 菜单，并修复其主菜单快捷键判断和按键入口；不包含其他模组的修复或性能改动。

## 安装

1. 安装游戏所需的 Lovely 和 Steamodded。
2. 下载本仓库：点击 **Code → Download ZIP**，然后解压。
3. 在 Windows 文件资源管理器地址栏输入 `%APPDATA%\Balatro\Mods`。
4. 创建 `ZokersModMenu` 文件夹，将本仓库的 **`ZokersModMenu.lua` 和 `lovely.toml`** 放入其中即可。
5. 如果已经安装原版，请先备份，再替换原来的同名文件；不要同时加载两份 Zoker 模组。
6. 重启游戏，按 **C** 打开菜单。

`manifest.json` 是上游的分发元数据，安装时不需要复制；Lua 文件自带 Steamodded 模组头信息；`lovely.toml` 用于安装按键入口修复，必须一同复制。

## 使用

- **初始数值**：设置开局属性，并打开相应开关。
- **初始物品**：选择开局的小丑牌、优惠券和标签。
- **编辑牌组**：设置花色、点数、增强、蜡封和版本；点击添加，Shift+点击移除。
- **对局赠送**：开始对局前，在主菜单将此开关设为“开”，进入对局后即可赠送金钱和物品。
- **免费重掷**：打开后使用原模组的免费商店重掷功能。
- **全部解锁**：使用原模组的内容解锁功能。

菜单快捷键可以在模组设置中修改。

### Windows 中文输入法

普通游玩和修改快捷键时，会暂停游戏窗口的文字输入模式，让按键直接触发快捷键；进入游戏文本框或 JokerDisplay 颜色输入框时恢复文字输入。不修改其他应用的输入法设置。离开游戏窗口时恢复原文字输入状态。

该行为通过 LÖVE 的 `love.keyboard.setTextInput` 实现。其他模组若自行建立文本框，应使用 `G.CONTROLLER.text_input_hook` 标记输入焦点。
